App chưa có chứng chỉ trả phí — cách vượt qua cảnh báo lần đầu

macOS — chuột phải vào app → Open → Open. Nếu báo app "bị hỏng", mở Terminal và chạy:

xattr -cr "/Applications/Tocky Voice.app"

Windows — SmartScreen hiện hộp xanh → More info → Run anyway.

Mã nguồn mở trên GitHub. Xem tất cả bản phát hành tại trang Releases.
